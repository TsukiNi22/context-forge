# CONTEXT FORGE - Quick Reference

**Binary:** `context-forge` (v1.0.0)  
**Purpose:** C++ CLI wrapper for ollama with context forging, daemon support, and IPC  
**Compiled:** `clang++` (C++20), output: `./context-forge`

---

## Architecture

```
main() → Forge::init() → parse args → Forge::run() → dispatch mode
                                        ↓
                    setup() | remove() | install() | exec() | server()
```

**Entry Point:** `src/forge/main.cpp`  
**Core Class:** `include/forge/Forge.hpp`  
**Init:** `src/forge/Forge-init.cpp` (ArgParser)  
**Impl:** `src/forge/Forge.cpp` (mode handlers)

### Modes

#### 1. `setup` — Install systemd user daemon
```bash
context-forge setup [-r <path>] [-a <ip>] [-p <port>] [-m <model>] [-s <system-prompt>] [-v <level>]
```

**Actions:**
- Creates `~/.config/systemd/user/context-forge.service`
- Stores server args in unit file
- Enables & starts daemon: `systemctl --user enable/start context-forge.service`
- Daemon config: `Restart=on-failure`, `RestartSec=2`, `WantedBy=default.target`

**Daemon will:**
- Start on user login
- Auto-restart on failure
- Run server mode with stored args

---

#### 2. `remove` — Remove systemd user daemon
```bash
context-forge remove [-v <level>]
```

**Actions:**
- Stops daemon: `systemctl --user stop context-forge.service`
- Disables daemon: `systemctl --user disable context-forge.service`
- Removes: `~/.config/systemd/user/context-forge.service`
- Reloads: `systemctl --user daemon-reload`

---

#### 3. `install-ollama` — Install ollama (requires root)
```bash
context-forge install-ollama [-v <level>]
```

**Actions:**
- Checks root: `geteuid() != 0` (throws if not root)
- Runs: `curl -fsSL https://ollama.com/install.sh | sh`
- Waits via `Process::wait()`, reports status

---

#### 4. `exec` — Client mode (execute with context forging)
```bash
context-forge exec [-v <level>] -c <bin> [<argument>]*
```

**Flags:**
| Flag | Alias | Value | Required |
|------|-------|-------|----------|
| `-c, --command` | `cmd` | `<bin> [<args>]*` | **Yes** |
| `-v, --verbose` | | `none\|basic\|advanced\|debug` | No |

**Purpose:** Start process, pipe output with ANSI preservation, remove duplicates, apply context forging rules (TODO: implement)

---

#### 5. `server` — Server mode (listen for clients)
```bash
context-forge server [-v <level>] [-r <rules>] [-a <ip>] [-p <port>] [-m <model>] [-s <system-prompt>]
```

**Flags:**
| Flag | Alias | Value | Env Var |
|------|-------|-------|---------|
| `-r, --rules <path>` | | Rules config path | |
| `-a, --ip <ip>` | | Ollama IP | `CONTEXT_FORGE_HOST_IPV4` |
| `-p, --port <port>` | | Ollama port | `CONTEXT_FORGE_HOST_PORT` |
| `-m, --model <path>` | | Ollama model name | `CONTEXT_FORGE_MODEL` |
| `-s, --system-prompt <path>` | | System prompt path | `CONTEXT_FORGE_SYSTEM_PROMPT` |

**Purpose:** Listen for client connections, apply rules, communicate with ollama via TCP (TODO: implement)

## libutils Integration

### Include Pattern
```cpp
#define _Exception    // AException, IException, FatalException, ErrorException
#define _Verbose      // set_verbose(), onBasicVerbose(), onAdvancedVerbose(), onDebugVerbose()
#define _Encapsulation // Process, Pipe, Dup, SharedMemory
#define _Arguments    // ArgParser, Settings, Setting
#define _Attribute    // _cold, _nodiscard, _unlikely, _hot, _unused
#include <utils/utils.hpp>
```

**Libraries Used:**
| Component | Header | Types/Functions |
|-----------|--------|-----------------|
| **Exception** | `<utils/exception/...>` | `IException`, `ErrorException`, `FatalException`, `InternalCode`, `Type` |
| **Verbose** | `<utils/verbose/Verbose.hpp>` | `Verbose` enum, `set_verbose()`, `on*Verbose()` macros |
| **Arguments** | `<utils/arguments/...>` | `ArgParser`, `Settings`, `Setting`, `CastType`, `ParsedUsages` |
| **Encapsulation** | `<utils/encapsulation/...>` | `Process`, `Pipe`, `Dup`, `Status` |
| **Network** | `<utils/network/...>` | **TODO:** `Server`, `Client`, `Socket` |

### Return Codes
```cpp
#define OK 0   // Success / Normal exit
#define KO -1  // Error
```

### Exception Handling
```cpp
try {
    core.init(argc, argv);
    core.run();
} catch (const utils::exception::IException& e) {
    if (e.isNone() && e.getCode() == utils::exception::InternalCode::Exit) return OK;
    std::cerr << e.formated() << std::endl;
    return KO;
}
```

**Exception Types:**
- `None` — Normal exit
- `Warning` — Warning (recoverable)
- `Error` — Error (recoverable)
- `Fatal` — Fatal error (non-recoverable)

**Custom Exception Codes:**
- `InternalCode` — Standard codes (Override, Process, Exit, ...)
- `ExternalCode` — Generated from JSON configs

## Coding Conventions

- **Naming:** `camelCase` for methods, `snake_case` for files
- **Members:** `_private` prefix
- **Attributes:** `_cold` (rarely called), `_nodiscard` (must use return), `_unlikely` (branch hint), `_hot` (frequently called)
- **Macros:** `OK`/`KO` for return codes
- **Style:** No comments unless explaining complex logic
- **Comments:** File headers with author/date/description
