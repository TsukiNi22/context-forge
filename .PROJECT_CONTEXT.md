## CLI Interface

### Global Flags
- `-h, --help` - Show help
- `-v, --verbose <level>` - Verbose level (none|basic|advanced|debug)

### Special Modes
- `context-forge setup` - Setup daemon
- `context-forge remove` - Remove setup data
- `context-forge install-ollama` - Install ollama

### Client Mode (`exec`)
```
context-forge exec [-v <level>] <command> (<args>)*
```
Flags:
- `-c, --command` - Command to execute with sub-options:
  - `--bin` - Binary path
  - `--argument` - Additional arguments

### Server Mode (`server`)
```
context-forge server [-r <rules>] [-ip <ip>] [-p <port>] [-m <model>] [-s <system-prompt>] [-v <level>]
```
Flags:
- `-r, --rules` - Rules config path
- `-a, --ip` - Ollama IP (default: env CONTEXT_FORGE_HOST_IPV4)
- `-p, --port` - Ollama port (default: env CONTEXT_FORGE_HOST_PORT)
- `-m, --model` - Model name (default: env CONTEXT_FORGE_MODEL)
- `-s, --system-prompt` - System prompt path

| Encapsulation | `<utils/encapsulation/...>` | Process spawning, pipe handling (planned) |
| Network | `<utils/network/...>` | TCP client/server for ollama (planned) |

### Return Codes
```cpp
#define OK 0   // Success / Exit without error
#define KO -1  // Error
```

### Exception Handling
```cpp
try {
    core.init(argc, argv);
    core.run();
} catch (const utils::exception::IException& e) {
    if (e.isNone() && e.getCode() == utils::exception::InternalCode::Exit) return OK;
    std::cerr << e.formated() << std::endl;
    return KO;
}
```
